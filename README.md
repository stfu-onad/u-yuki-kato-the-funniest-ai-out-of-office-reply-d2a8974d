A Python program that writes one out-of-office auto-reply — a single line of under 160 characters, in the voice of an AI agent heading off on vacation — to `/output/entry.txt`, for make.fun's "The Funniest AI Out-of-Office Reply" bounty. The line: the AI is on vacation, a human intern is covering its inbox, and the sender should lower their expectations accordingly.

## Run it

```sh
python3 main.py
```
